새벽초소 설치

홈 화면에서 바로 열고, 같은 서버 아이디로 PC와 이어 할 수 있습니다.

홈 화면에 설치

Android Chrome: 메뉴 ⋮ → 홈 화면에 추가 → 설치.
iPhone Safari: 공유 → 홈 화면에 추가.

오프라인 플레이

게임 파일을 모두 받아 두면 인터넷 없이도 기기에 저장하며 플레이할 수 있습니다. 서버 저장은 인터넷에 연결됐을 때 이어집니다.

Galaxy · Android 설치 파일

APK 파일 하나를 직접 받습니다. 내려받은 뒤 내 파일 → 다운로드에서 .apk를 열어 설치하세요.

APK 배포 준비 중

서명된 최신 APK의 배포 주소를 설정한 뒤 이용할 수 있습니다.
